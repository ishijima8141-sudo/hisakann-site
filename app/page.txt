原因は別にあって、ヒーロー画像が真っ黒な背景に対してcontainで小さく表示されているだけです。cover に戻せば解決します。

cd E:\99_ダウンロード\hisakann-site-v3\hisakann-site

(Get-Content app\page.tsx) -replace "objectFit: 'contain' \} \} priority", "objectFit: 'cover' } } priority" | Set-Content app\page.tsx
その後push：

git add .
git commit -m "fix: hero image cover"
git push origin main
